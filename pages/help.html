Help & Tutorials

Guides for getting set up, going live and fixing common problems.

Getting started

  1. Camera Studio → Start Camera, choose Horizontal or Vertical, pick a quality.
  2. Recording Studio → record locally and download. No account needed.
  3. Platform Connections → connect YouTube or Facebook, or add a custom RTMP/WHIP destination.
  4. Start Streaming → pick destinations, pass the readiness checklist, press Go Live.

Important limitations

  • GitHub Pages and Google Apps Script cannot carry live video. Live broadcasting uses WebRTC/WHIP to a media gateway (optional, self-hosted, open source) or directly to a WHIP endpoint.
  • Multi-platform streaming is available only when a relay gateway is configured and healthy.
  • Instagram has no general public Live API. Only accounts with Instagram's official live-production access can stream with an RTMP key.
  • Facebook needs a Meta app with approved permissions; apps in Development mode work only for people with a role on the app.
  • Mobile operating systems may pause the camera or network when the screen locks or the app is in the background. Background streaming is not guaranteed.
  • Recording formats depend on your browser. MP4 is not assumed.

Troubleshooting

Camera permission blocked
Tap the lock icon in the address bar → Permissions → set Camera and Microphone to Allow, then reload. On Android also check Settings → Apps → your browser → Permissions.
Camera is busy
Another app or tab is using the camera. Close video-call apps and other camera tabs, then press Start Camera again.
Only one camera is listed on my phone
Some browsers show device names only after permission is granted. Start the camera once, then open Device Settings and refresh.
“Gateway unreachable”
Check the URL uses https://, the certificate is valid, and CORS allows this website's origin. Run Diagnostics for details.
Broadcast keeps reconnecting
Use the Low bandwidth preset, move closer to your router, and avoid switching between Wi-Fi and mobile data while live.
